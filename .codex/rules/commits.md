# Commit Rules

Use Conventional Commits.

Format:
- `type(scope): message`

Preferred types:
- `feat`
- `fix`
- `refactor`
- `chore`
- `test`
- `docs`

Rules:
- Keep commits small and focused.
- Do not mix unrelated infra, domain, and UI changes in the same commit unless the feature is inseparable.
- Prefer one logical change per commit.
- Use scopes that match the actual project area when possible.
